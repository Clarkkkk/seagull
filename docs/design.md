# Seagull-App / Gullivel 旅行规划应用设计文档

## 1. 项目背景与愿景

### 1.1 项目简介

Seagull-App 是一款面向旅行爱好者的全流程旅行规划与记录应用，旨在解决用户从旅行前的灵感收集与行程规划，到旅行中的实时导航与信息查询，再到旅行后的回忆记录与分享的完整需求链路。我们的目标是打造一款能够真正理解旅行者需求，提供无缝体验的旅行伴侣应用。

### 1.2 产品愿景

通过精心设计的用户体验和智能化功能，我们希望：

- **简化旅行规划**：将复杂的旅行策划变成轻松愉快的过程
- **增强旅途体验**：提供恰到好处的提醒与建议，不打扰真正的旅行体验
- **保存珍贵记忆**：将旅途中的点滴转化为可长久保存的精美回忆
- **建立旅行社区**：连接志同道合的旅行者，分享经验与灵感

### 1.3 设计使命

我们的设计使命是创造一个既实用又充满情感连接的数字空间，让用户在每一次与应用的互动中都能感受到：

> "这是一个真正理解我，并能陪伴我探索世界的旅行伙伴。"

## 2. 用户洞察

### 2.1 目标用户群体

**核心用户画像**：
- **年龄**：25-40岁的中青年群体
- **特点**：热爱旅行、注重体验、生活品质要求较高
- **技术接受度**：中高，习惯使用智能手机和各类应用
- **旅行习惯**：每年有1-3次自助旅行计划，重视旅行规划和记录
- **痛点**：旅行规划耗时、信息分散、协同困难、旅途中常有变化

**次要用户群体**：
- 18-25岁的年轻学生群体（经济有限但时间充裕）
- 40-55岁的成熟旅行者（经济充裕但时间有限）

### 2.2 用户需求层次

遵循马斯洛需求层次理论，我们识别出旅行者的需求层次：

1. **功能性需求**：高效规划、便捷查询、实时导航
2. **安全性需求**：行程有保障、信息安全可靠
3. **社交性需求**：与同伴共享、获得社区认同
4. **尊重性需求**：个性化体验、专业旅行者身份认同
5. **自我实现需求**：记录个人成长、完成旅行梦想

### 2.3 用户旅程地图

用户在不同阶段的情感曲线和关键接触点：

**规划阶段**：
- 情感曲线：期待→兴奋→压力→满足
- 关键接触点：灵感收集、行程编排、方案确认

**旅行阶段**：
- 情感曲线：兴奋→探索→疲惫→惊喜→满足
- 关键接触点：实时导航、信息查询、突发事件处理

**回味阶段**：
- 情感曲线：怀念→分享→自豪→期待
- 关键接触点：记忆整理、社交分享、未来规划

## 3. 设计原则

### 3.1 核心设计原则

1. **亲近感**
   - 设计应给人温暖、友好的感觉，如同一位经验丰富却不居高临下的旅行伙伴
   - 通过圆润的图形、柔和的色彩、自然的动效传达亲近感
   - 语言风格应轻松友好，避免过于专业或生硬的表达

2. **直观性**
   - 界面结构清晰明了，用户无需思考即可理解
   - 关键功能一目了然，重要信息突出显示
   - 交互逻辑符合用户心智模型，减少学习成本

3. **细节精致**
   - 精心打磨每一处交互细节，创造愉悦的使用体验
   - 通过微妙的视觉反馈增强用户对操作的确定感
   - 在恰当位置运用令人惊喜的微动效和转场效果

4. **情感共鸣**
   - 理解并呼应用户在旅行不同阶段的情感需求
   - 通过设计元素触发用户的旅行记忆和向往
   - 在关键节点提供情感化的鼓励和肯定

5. **一致性与惊喜平衡**
   - 保持整体设计语言的一致性，建立用户信任
   - 在不影响使用效率的前提下，适度加入令人惊喜的设计巧思
   - 常规功能保持稳定，创新体验带来惊喜

### 3.2 设计巧思方向与优先级

1. **地图交互创新** [优先级：中]
   - 行程路线可视化时融入手绘地图元素，增添人文气息
   - 拖拽调整路线时加入适度的物理惯性，提升真实感 [MVP后迭代]
   - 通过微妙的视角转换效果，在 2D 与 3D 视图间自然过渡 [MVP后迭代]

2. **时间感知表达** [优先级：高]
   - 行程时间轴设计灵感来源于传统旅行者笔记 [MVP阶段实现]
   - 过去的行程点带有"回忆滤镜"效果，未来行程点则充满期待感的设计语言 [MVP阶段简化版本]
   - 当日行程随时间推移的微妙视觉变化，如光影效果随一天时间变化 [MVP后迭代]

3. **情感化反馈** [优先级：低-中]
   - 完成行程规划时的成就感强化，如个性化的虚拟纪念品 [MVP后迭代]
   - 旅行打卡时的微小庆祝动效，既满足成就感又不打断体验 [MVP后迭代]
   - 生成回忆时的惊喜呈现方式，如渐进式展现过去的精彩瞬间 [MVP后迭代]

4. **自然元素融合** [优先级：低]
   - 天气信息呈现融入环境设计，如雨天页面有微妙的雨滴效果 [MVP后迭代]
   - 季节变化在应用视觉元素中的微妙体现 [MVP后迭代]
   - 地理位置相关的文化元素巧妙融入界面细节 [MVP后迭代]

**实施策略**：
- **MVP阶段**：首先确保核心功能完整、基础交互流畅，选择1-2个高优先级的设计巧思实现
- **标志性体验**：在后续迭代中，逐步加入这些"魔法感"的设计元素，作为应用的标志性体验
- **增量式实现**：每次更新加入一个新的"惊喜"，保持用户新鲜感和探索欲

## 4. 品牌识别系统

### 4.1 品牌定位

- **核心品牌价值**：自由、探索、从容、陪伴、记忆
- **品牌个性**：友善的、可靠的、聪明的、松弛的、有趣的
- **品牌愿景**：成为每位旅行者最信赖的数字旅行伙伴，让规划像海风一样轻盈

### 4.2 命名与标识

- **名称**：Gullivel / 旅鸥
  - 寓意：Gullivel = Gulliver's traveling 的灵感缩写，传达“永远在路上”的探索精神
  - 中文名“旅鸥”：海鸥象征自由与悠闲，也代表对海岸线与远方的天然向往

- **标志设计要点**：
  - 简洁明了，确保在小尺寸下仍有良好辨识度
  - 融入海鸥的轮廓/翅膀意象，可结合海浪弧线或罗盘/航线元素体现“旅行与规划”
  - 考虑动态版本：如海鸥掠过海面、航线逐步绘制，用于启动画面和关键转场

- **标语**：「遇见世界，遇见自己」

### 4.3 应用图标

- 主图标应包含品牌标志的核心元素
- 设计需考虑在不同背景和操作系统下的适应性
- 图标应传达出"旅行"与"规划"的核心理念
- 考虑季节性或特殊活动的图标变体
  - 默认版本建议以海洋蓝为底色，以海鸥/航线为主形，确保在深浅模式下均清晰

## 5. 视觉设计系统

### 5.1 色彩系统

**主色调**：
- **品牌主色/首要行动色**：海洋蓝（#1E88E5）
  - 寓意：自由、广阔、可靠与方向感（像海上的航标一样清晰）
  - 应用：品牌标识、主要CTA按钮（如"开始规划"、"确认"、"下一步"）、关键操作点、链接与高亮状态
  - 使用原则：用于“引导与确认”，避免全屏高饱和大面积铺色；搭配大面积中性色营造松弛与呼吸感

- **功能性辅助色**：
  - 天光浅蓝（#8ECDF5）：代表天空与轻盈
    - 应用：信息提示背景、选中态浅底、天气信息卡片
  - 海松绿（#2FBF9B）：代表海岸与自然
    - 应用：自然景点标记、完成状态、积极反馈的辅助强调
  - 沙滩米（#F3E8D6）：代表海岸与度假感
    - 应用：卡片底色变体、插图点缀、空状态背景的温度补偿
  - 暖灰色（#95A5A6）：中性色调，提供平衡
    - 应用：次要按钮、分割线、背景元素、弱化信息

**功能色**：
- 成功色：#27AE60
- 警告色：#F39C12
- 错误色：#E74C3C
- 信息色：#3498DB

**中性色**：
- 纯白：#FFFFFF
- 象牙白：#F9F9F7（背景色）
- 浅灰：#EAEAEA
- 中灰：#95A5A6
- 深灰：#34495E
- 近黑：#2C3E50

**色彩应用原则**：
- 主色用于关键行动点和品牌识别
- 辅助色用于功能区分和内容分类
- 大面积使用中性色，确保内容清晰和减少视觉疲劳
- 颜色应用需考虑无障碍设计标准

### 5.2 排版系统

**字体选择**：
- 中文主字体：思源黑体/思源宋体
- 英文主字体：SF Pro Text / Roboto
- 数字字体：DIN

**字体层级**：
- 大标题：24-32px，粗体
- 标题：20-24px，中粗
- 副标题：18px，常规/中粗
- 正文：16px，常规
- 次要文本：14px，常规
- 辅助文本：12px，常规/轻盈

**排版原则**：
- 保持一致的行高和字间距
- 确保在不同屏幕尺寸下的可读性
- 重要信息通过字重和颜色变化突出
- 文本块合理分段，避免长段落

### 5.3 图标与插图

**图标系统**：
- 设计风格：线性图标结合柔和的填充效果
- 一致的圆角和笔触粗细
- 核心功能使用独特的品牌化图标
- 常规功能采用通用且易理解的图标语言

**插图策略**：
- 核心场景使用定制插图，传达品牌个性
- 插图风格温暖、友好，带有适度的手绘感
- 颜色与应用整体色彩系统一致
- 插图需考虑不同文化背景用户的理解

### 5.4 空间与布局

**网格系统**：
- 基础8点网格系统
- 内容区块内边距一致（16px或24px）
- 卡片圆角统一（12px）
- 元素间距遵循8的倍数（8, 16, 24, 32, 48）

**布局原则**：
- 信息层次清晰，重要内容优先展示
- 相关功能分组，减少认知负担
- 关键操作区域考虑单手操作舒适区
- 内容密度适中，避免过于拥挤或空旷

### 5.5 动效设计

**动效风格**：
- 自然、流畅、有机的动效
- 动效速率参考自然界运动（如叶片摇曳、水波涟漪）
- 避免过于机械或夸张的效果

**关键动效场景**：
- 转场动效：页面间的自然过渡
- 状态变化：加载、提交、完成等状态的视觉反馈
- 微交互：按钮、开关、滑块等控件的响应动效
- 引导动效：首次使用功能时的提示动画

**动效实现原则**：
- 动效应服务于用户体验，不应成为干扰
- 性能优先，避免复杂动效导致卡顿
- 提供动效减弱选项，照顾对动画敏感的用户

## 6. 交互设计规范

### 6.1 手势交互

**核心手势**：
- 点击：基础操作，触发按钮和控件
- 长按：显示上下文操作或预览内容
- 滑动：浏览内容、切换页面、显示/隐藏功能
- 双指缩放：地图和图片的缩放操作
- 拖拽：调整行程项目顺序、在地图上移动标记

**特色交互**：
- 行程规划中的"时间轴拖拽"手势
- 灵感收集的"滑动分类"手势
- 旅行记忆的"时光回溯"手势

**交互反馈**：
- 所有手势操作都应有适当的视觉反馈
- 反馈形式包括颜色变化、轻微位移、形状变化等
- 关键操作添加触觉反馈（振动）

### 6.2 导航模式

**主导航**：
- 底部标签栏：提供主要功能区域快速访问
- 分区明确：首页（仪表盘）、行程（规划）、发现（社区）、回忆、我的

**情境感知首页**：
- 默认状态（非旅行中）：展示"即将开始的行程"、"继续规划草稿"、"灵感推荐"等卡片
- 旅行中状态：自动切换为"今日行程仪表盘"，集中呈现当前活动、导航、天气等行中功能
- 智能转换：基于行程日期和地理位置，自动感知用户状态并调整界面

**次级导航**：
- 顶部导航栏：显示当前位置和返回路径
- 情境菜单：根据当前任务提供相关操作
- 滑动抽屉：隐藏非核心但常用的功能

**导航原则**：
- 用户应随时知道自己在哪里
- 关键功能触手可及（最多2-3步可达）
- 相关功能在逻辑上分组
- 提供明确的返回路径

### 6.3 表单与控件

**输入控件**：
- 文本输入框：边框明确，焦点状态突出
- 选择器：下拉、日期、时间选择器设计一致
- 开关与复选框：状态变化明确，触控区域充分
- 滑块：精确控制数值，提供适当反馈

**操作反馈**：
- 加载状态：使用品牌化的加载动画
- 成功状态：简洁明了的成功提示
- 错误状态：友好的错误信息，并提供解决建议
- 空状态：有引导性的空状态设计，而非简单留白

**表单设计原则**：
- 字段分组逻辑，减少认知负担
- 实时验证，及早发现并指出问题
- 智能默认值，减少用户输入负担
- 渐进式表单，复杂任务分步完成

### 6.4 微交互设计

**关键微交互场景**：
- 收藏地点的星标动效
- 完成清单项的打勾动效
- 路线优化的进度展示
- 旅行打卡的成就感强化

**微交互设计原则**：
- 细节但不微小：确保用户能注意到反馈
- 合理时机：在用户期望反馈的时刻提供
- 个性与一致：体现品牌特色但保持系统一致性
- 目的明确：每个微交互都服务于特定功能目标

## 7. 内容设计

### 7.1 语言风格

**语气基调**：
- 友好而不过于随意
- 专业而不生硬
- 鼓励性的正面表达
- 简洁明了，避免冗长

**特色表达**：
- 旅行相关的精选用词（如"启程"、"启航"而非"开始"）
- 根据功能区域微调语气（规划区域更实用，记忆区域更抒情）
- 适度使用旅行隐喻和类比

**文案原则**：
- 简洁为王：用最少的文字传达关键信息
- 实用为本：帮助用户完成任务的文案优先
- 人性化：理解并呼应用户当前情境
- 全球化：考虑不同文化背景的理解差异

### 7.2 图片与媒体

**图片风格**：
- 应用内置图片：鲜活、明亮、自然的旅行场景
- 用户生成内容：提供简单的优化滤镜
- 图标与插图：一致的设计语言

**媒体处理原则**：
- 优化加载：渐进式加载，避免空白等待
- 智能裁剪：确保关键内容在不同尺寸下可见
- 适当压缩：平衡质量和性能
- 多种格式：支持图片、视频、360°全景等多媒体形式

### 7.3 数据可视化

**地图可视化**：
- 自定义地图样式，符合应用整体风格
- 清晰的POI标记系统，不同类型有明确区分
- 路线展示既美观又实用，强调关键信息

**行程可视化**：
- 时间轴设计既直观又美观
- 行程密度的热力图展示
- 旅行统计数据的图表设计

**可视化原则**：
- 信息优先：美观不应牺牲清晰度
- 直观理解：减少理解数据所需的认知负担
- 一致性：整个应用中的数据展示风格一致
- 响应式：在不同屏幕尺寸下保持可读性

## 8. 模块设计重点

### 8.1 灵感收集系统

**设计重点**：
- 轻量级的收集界面，最小化输入阻力
- 视觉化的灵感展示，如瀑布流布局
- 直观的分层管理视觉表达
- 智能解析的流畅反馈机制

**创意方向**：
- 灵感"罐子"的视觉隐喻
- 从混沌到有序的视觉转变过程
- 与实体旅行笔记本的情感连接

### 8.2 行程规划中心

**设计重点**：
- 地图与时间轴的无缝集成
- 直观的拖拽交互与即时反馈
- 约束条件的视觉化表达
- 智能建议的自然呈现方式

**创意方向**：
- 结合传统纸质地图与现代数字交互
- "魔法"感的路线优化视觉效果
- 旅行者控制台的操作体验

### 8.3 情境感知首页/仪表盘

**设计重点**：
- 智能状态检测与无缝切换机制
- 非旅行状态的首页内容层级与个性化推荐
- 旅行中状态的关键信息布局与即时功能
- 过渡动效设计，让状态切换自然流畅

**创意方向**：
- 数字化的个人旅行助手，随时理解用户需求
- 沉浸式的状态转换体验，从期待到体验
- 智能推荐系统的视觉表达

**具体设计要点**：
- **默认状态（非旅行中）**：
  - 未来行程预览卡片，带有倒计时和天气预告
  - 继续编辑的规划草稿，视觉上有"未完成"的提示
  - 基于季节、兴趣的目的地灵感推荐
  - 社区热门内容的精选展示

- **旅行中状态**：
  - 聚焦当日行程的视觉层级设计
  - 关键信息（交通、预订、天气）的醒目呈现
  - 实时状态更新与智能调整建议
  - 离线模式的明确指示与应急功能入口

- 照片与文字的优雅排版
- 分享体验的完整设计
- 成就感的视觉强化

**创意方向**：
