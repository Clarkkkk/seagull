# Deer-App 用户登录产品需求文档

## 1. 需求背景

Deer-App 作为一款面向旅行爱好者的全流程旅行规划与记录应用，需要建立完善的用户账户系统，以支持个性化的旅行内容管理、数据安全存储、社区互动以及多设备同步等核心功能。

随着应用功能的丰富和用户数据的积累，建立安全可靠的用户身份认证机制变得至关重要。用户登录系统作为应用的基础设施，不仅关系到用户体验的连贯性，更是保障用户数据安全和隐私的第一道防线。

## 2. 业务目标

### 2.1 核心目标

1. **数据持久化与个性化**：
   - 为用户提供稳定可靠的数据存储方案，确保行程规划、收藏地点、游记等内容可以长期保存
   - 支持用户个性化设置和偏好记录，提供定制化的使用体验

2. **多设备同步与无缝体验**：
   - 允许用户在多个设备间无缝切换，实现行程数据的实时同步
   - 提供统一的用户体验，保持设置和偏好的一致性

3. **数据安全与隐私保护**：
   - 建立完善的身份验证机制，确保只有授权用户能够访问个人数据
   - 防止未授权访问和潜在的数据泄露风险
   - 满足数据隐私法规要求（如GDPR、CCPA等）

4. **社区功能基础支持**：
   - 为用户互动、内容分享和协作编辑提供身份基础
   - 支持用户声誉系统和社区贡献度量

5. **商业模式支持**：
   - 为未来可能的订阅制、增值服务等商业模式提供用户身份基础
   - 支持用户消费行为分析和个性化推荐

### 2.2 量化目标

1. **用户体验目标**：
   - 首次注册流程完成时间 < 2分钟
   - 常规登录流程完成时间 < 30秒
   - 账号相关问题（如密码重置）解决时间 < 5分钟
   - 登录成功率 > 99%

2. **安全目标**：
   - 减少90%以上的未授权访问风险
   - 敏感操作（如修改密码、注销账号）100%进行多因素验证
   - 异常登录行为检测准确率 > 95%

3. **技术目标**：
   - 支持初期10万级日活用户规模，为未来百万级用户做架构准备
   - 登录服务可用性 > 99.9%
   - 认证响应时间 < 300ms
   - 多设备数据同步延迟 < 5秒

## 3. 用户登录系统价值

### 3.1 对用户的价值

1. **数据安全保障**：
   - 保护用户的旅行规划、照片、笔记等私人数据不被他人未授权访问
   - 提供账号恢复和密码重置机制，避免数据丢失风险

2. **跨设备体验一致性**：
   - 无论在手机、平板还是电脑上访问，都能获得完整且一致的数据
   - 在新设备上轻松恢复所有历史数据和设置

3. **个性化体验**：
   - 根据用户历史行为和偏好提供定制化推荐
   - 记住用户的使用习惯和设置，提供更贴心的服务

4. **社交互动能力**：
   - 分享旅行计划和游记给特定好友或公开到社区
   - 参与协作规划，与同伴共同编辑行程

### 3.2 对产品的价值

1. **内容生态建设**：
   - 用户产生的内容（UGC）构成产品核心价值，用户账号是UGC归属的基础
   - 优质内容可被沉淀和分享，形成产品独特的内容生态

2. **防盗版与保护知识产权**：
   - 用户验证机制有效防止应用被盗版和滥用
   - 保护产品核心算法和数据资产不被非法获取

3. **数据分析基础**：
   - 建立用户行为分析体系，了解用户使用模式和偏好
   - 为产品迭代和功能优化提供数据支持

4. **商业化可能性**：
   - 为付费订阅、增值服务等商业模式提供用户身份基础
   - 支持精准营销和个性化推荐

5. **合规与风险管控**：
   - 满足各地区数据隐私法规要求
   - 降低数据泄露和法律风险

## 4. 具体功能需求

### 4.1 用户注册

1. **多渠道注册**：
   - **手机号+验证码注册**：
     - 手机号输入后自动检测格式正确性（11位数字，以1开头）
     - 用户点击获取验证码按钮后，按钮变为倒计时状态（60秒）
     - 验证码有效期为10分钟，6位数字
     - 同一手机号1小时内最多发送5次验证码
     - 验证码输入错误3次后，需重新获取
   
   - **邮箱+密码注册**：
     - 邮箱格式实时验证
     - 验证邮件5分钟内发送，24小时内有效
     - 邮件包含验证链接，点击后自动完成验证
     - 验证邮件发送后，提供重新发送选项（间隔2分钟）
   
   - **预留第三方账号接口**：
     - 系统预留OAuth2.0集成接口，便于后续快速接入微信、苹果等第三方登录

2. **注册流程**：
   - **输入基本信息**：
     - 手机号/邮箱作为第一步必填项
     - 用户名支持2-20个字符，支持中英文、数字、下划线
     - 基本信息页面包含隐私政策和用户协议勾选项（默认不勾选）
   
   - **验证身份**：
     - 短信验证码：六位数字，输入框支持粘贴和自动识别
     - 邮箱验证：点击邮件中的链接后，自动跳转至注册后续流程
     - 验证失败时显示明确错误提示，并提供重新发送选项
   
   - **设置密码**（可选）：
     - 密码长度8-20位，必须包含字母和数字
     - 密码强度实时显示（弱/中/强）
     - 手机验证码登录路径可跳过此步骤
     - 提供"显示/隐藏密码"切换选项
   
   - **完善个人资料**（可选）：
     - 默认头像和用户昵称
     - 头像支持拍照、从相册选择、内置模板三种方式
     - 提供"跳过"选项，可在个人中心稍后完善
     - 完成后直接进入应用主界面

3. **注册校验**：
   - **手机号/邮箱唯一性检查**：
     - 实时检查手机号/邮箱是否已被注册
     - 已注册用户提示"该账号已注册，请直接登录"并提供登录入口
     - 注册时检测手机号归属地，海外号码需额外验证
   
   - **用户名合规性检查**：
     - 用户名不可与系统保留名称冲突
     - 字符长度限制：2-20个字符
     - 实时提示用户名可用性状态
   
   - **密码强度检查**：
     - 密码必须包含字母和数字，长度8-20位
     - 密码强度分级显示：弱（纯数字或字母）、中（字母+数字）、强（大小写字母+数字+特殊字符）
     - 极弱密码（如123456）会被系统拒绝并提示

### 4.2 用户登录

1. **登录方式**：
   - **手机号+验证码登录**（主推）：
     - 支持记住上次登录手机号
     - 验证码机制与注册流程相同（60秒倒计时，10分钟有效期）
   
   - **账号+密码登录**：
     - 支持使用用户名/手机号/邮箱 + 密码组合登录
     - 密码连续输错5次后，需要额外验证（短信验证码/图形验证码）
     - 提供"记住密码"选项（默认7天有效期）
     - 密码输入框提供"显示/隐藏密码"切换
   
   - **第三方账号快捷登录**（预留）：
     - 预留微信、苹果账号、Google等第三方登录接口
     - 第三方账号首次登录时，提示关联手机号（可选跳过）
     - 已关联手机号的第三方账号登录后，自动关联到现有账户
   
   - **记住登录状态**：
     - 默认登录状态保持30天
     - 用户可在设置中修改自动登录有效期（7天/30天/90天/永久）
     - 敏感操作（如支付、账户设置更改）仍需二次验证

2. **登录失败处理**：
   - **友好的错误提示**：
     - 提供错误原因和解决建议
     - 错误信息使用自然语言描述，避免技术术语
     - 针对验证码输错的情况，提供"重新获取"快捷按钮
     - 基于安全原因，不区分密码错误和账号不存在
   
   - **密码找回通道**：
     - 提供"忘记密码"入口，位于密码输入框下方
     - 支持通过绑定手机号/邮箱重置密码
     - 密码重置后，其他设备同步退出登录，现有token失效
     - 提供引导式密码重置流程，每步骤提供清晰说明
   
   - **防暴力破解保护**（后续实现）：
     - 同一IP地址短时间内多次登录失败后进行限流
     - 连续5次密码错误后，强制要求图形验证码
     - 连续10次密码错误后，该账号临时锁定30分钟
     - 系统记录异常登录尝试，并在用户成功登录后提醒

### 4.3 账户安全

1. **密码管理**：
   - **密码修改**：
     - 修改密码前需验证原密码或短信验证码
     - 新密码不能与最近3次使用的密码相同
     - 密码修改成功后，向用户注册邮箱发送通知
     - 密码变更后，所有设备需重新登录（当前设备除外）
   
   - **密码重置**（忘记密码）：
     - 支持通过绑定手机/邮箱进行身份验证
     - 验证通过后可直接设置新密码，无需输入原密码
     - 重置流程全程不超过3个步骤
     - 密码重置操作将通过邮件/短信通知用户
   
   - **定期密码更新提醒**（可选）：
     - 用户可选择开启密码定期更新提醒（默认关闭）
     - 提醒周期可设置为30/60/90/180天
     - 提醒以轻量级通知形式展示，不强制更改
     - 提供"一键生成强密码"功能辅助用户创建安全密码

2. **账户保护**：
   - **登录异常提醒**：
     - 检测到以下情况时发送安全提醒：新设备登录、异地登录、长时间未登录后重新登录
     - 安全提醒通过App内通知、短信和邮件（可配置）发送
     - 提供一键查看详情和一键下线可疑设备功能
     - 用户可定制安全提醒敏感度（高/中/低）
   
   - **账户锁定机制**：
     - 密码连续错误10次触发账户锁定，锁定时间30分钟
     - 系统检测到可疑操作时，可主动锁定账户并通知用户
     - 锁定状态下，仅能通过短信/邮箱验证码解锁
     - 账户锁定后，向用户所有验证渠道发送通知

3. **设备管理**：
   - **查看当前登录的所有设备**：
     - 展示所有当前登录设备的信息：设备类型、设备名称、登录地点、最近活跃时间
     - 设备按最近活跃时间排序
     - 显示当前使用的设备标记
     - 支持搜索和筛选设备列表
   
   - **远程下线其他设备**（后续实现）：
     - 支持单个设备下线和一键下线所有其他设备
     - 下线操作实时生效，目标设备立即退出登录状态
     - 设备下线后通知对应设备用户
     - 提供下线确认机制，避免误操作

### 4.4 用户中心

1. **个人资料**：
   - **基本资料管理**：
     - 用户昵称：2-20个字符，支持修改频率限制（30天可修改1次）
     - 头像：支持拍照、从相册选择、系统提供的20+模板头像
   
   - **联系方式管理**：
     - 手机号：支持更换（90天内限制更换1次），需验证新手机
     - 邮箱：可添加、更换和验证，最多绑定3个
     - 紧急联系人：可选设置（用于账号找回和安全通知）
     - 每次修改联系方式都需要二次验证

2. **账户管理**：
   - **账号注销**：
     - 注销前需完成身份验证（短信+邮件双重验证）
     - 注销前明确告知数据删除范围和影响
     - 设置14天的"冷静期"，期间可随时取消注销
     - 注销后，用户数据处理遵循隐私政策（部分匿名保留/完全删除）
   
   - **数据导出**（后续实现）：
     - 支持导出内容：个人资料、行程计划、收藏内容、笔记等
     - 导出格式：PDF（浏览）和JSON（数据迁移）
     - 导出请求处理时间：24小时内
     - 导出文件有效期：7天，过期需重新申请

### 4.5 协作与分享

1. **内容分享**：
   - **行程规划分享**：
     - 分享模式：公开链接/私密链接（需密码访问）/指定用户
     - 链接有效期设置：24小时/7天/30天/永久
     - 分享权限设置：仅查看/允许编辑
     - 分享后可随时修改权限或取消分享
   
   - **社交媒体分享集成**（后续实现）：
     - 支持一键分享到微信、微博、QQ等主流社交平台
     - 分享内容可自定义（标题、封面图、简介）
     - 社交分享带有应用下载入口
     - 分享统计（查看次数、点击率、转化率）

2. **协作编辑**：
   - **邀请协作者**：
     - 邀请方式：手机号/邮箱/应用内好友选择/分享链接
     - 邀请消息通过应用内通知、短信和邮件（可配置）发送
     - 受邀用户未注册时，引导完成快速注册流程
     - 邀请有效期：7天（可自定义1-30天）
   
   - **编辑历史与版本控制**：
     - 记录所有编辑操作及操作人
     - 支持查看30天内的编辑历史
     - 提供版本对比功能，可视化显示变更内容
     - 支持回滚到指定历史版本

## 5. 界面原型描述

### 5.1 启动与引导界面

1. **启动屏幕**：
   - 全屏展示App Logo和品牌名称
   - 底部显示简短标语"规划旅行，记录生活"
   - 加载动画简洁流畅，展示时间不超过3秒
   - 底部显示版本号和版权信息

2. **引导页**：
   - 仅首次安装显示，共3页轮播
   - 每页包含全屏插图、特性标题和简短描述
   - 页面指示器显示当前页/总页数
   - 最后一页显示"开始体验"按钮
   - 任意页面可通过"跳过"按钮直接进入登录页

3. **登录/注册选择页**：
   - 顶部品牌Logo，中部两个主按钮：登录/注册
   - 底部提供隐私政策和用户协议链接

### 5.2 注册流程界面

1. **手机号注册页**：
   - 顶部标题"注册新账号"，下方副标题"请输入手机号"
   - 国家/地区选择器（默认中国+86）
   - 手机号输入框，带清除按钮，实时显示格式检查结果
   - "获取验证码"按钮（点击后变为60秒倒计时）
   - 底部隐私政策勾选框，默认未勾选
   - 底部提供"已有账号？登录"入口

2. **验证码输入页**：
   - 顶部显示已输入的手机号，带"编辑"按钮
   - 6位验证码输入框，支持自动分格，每输入一位自动跳到下一格
   - 验证码下方显示"验证码已发送至+86 XXX****XXXX"
   - 倒计时按钮"重新获取(59s)"
   - "验证"按钮在输入满6位后自动激活

3. **个人资料设置页**（可选）：
   - 头像上传区：默认占位图+相机图标，点击可选择上传方式
   - 用户名输入框，下方实时显示可用性检查结果
   - 密码设置区（可选步骤），包含密码输入框和确认密码输入框
   - 密码强度指示条，显示弱/中/强三级
   - "完成注册"按钮
   - "跳过"小字链接，点击后使用系统生成的随机昵称和默认头像

### 5.3 登录界面

1. **手机号登录页**：
   - 手机号输入框（预填上次登录手机号）
   - 默认使用密码登录
   - "其他登录方式"下拉选项，展开显示验证码登录、邮箱登录等
   - 记住登录状态开关（默认开启）
   - "登录"按钮，点击后显示加载动画
   - 底部提供"注册新账号"入口

2. **密码登录页**：
   - 账号输入框（支持手机号/邮箱/用户名）
   - 密码输入框，带"显示/隐藏"切换和"忘记密码"链接
   - "登录"按钮
   - 多次密码错误后，增加图形验证码输入区域
   - 底部社交账号快速登录区域（预留）

### 5.4 用户中心界面

1. **个人资料页**：
   - 顶部大头像展示区，点击可更换
   - 用户昵称、账号ID、个人简介编辑区
   - 基础信息设置：性别、生日、地区等
   - 联系方式管理：手机号（带已验证标识）、邮箱列表
   - 每项右侧提供编辑入口
   - 底部"保存"按钮

2. **隐私设置页**：
   - 分区域展示不同隐私设置：
     * 个人资料可见性设置
     * 搜索可见性设置
     * 内容隐私默认设置
     * 数据共享与分析设置
   - 每项使用开关或下拉选择控制
   - 变更敏感设置时弹出确认对话框
   - 底部提供"隐私政策"入口

3. **账号管理页**：
   - 账号注销入口，带醒目警告标识
   - 数据导出功能，包含选择导出内容和格式的选项
